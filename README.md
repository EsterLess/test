# NUTRI — Personal Edition

Нативный Android-проект для персонального трекера питания, ориентированного на российский рынок.

## Текущий этап: Foundation 0.1.0

Реализовано:
- Kotlin + Jetpack Compose;
- тёмная дизайн-система NUTRI;
- пять основных разделов;
- экран дневника и базовый опрос планировщика питания;
- интерактивный водный счётчик;
- сохранение объёма воды, дневной цели и настроек через Preferences DataStore;
- базовые анимационные переходы;
- GitHub Actions для автоматической сборки debug APK.

Пока не подключено:
- реальная камера и AI Vision;
- распознавание штрихкодов;
- российские каталоги продуктов;
- расчёт КБЖУ на основе проверенных пищевых данных;
- напоминания Android;
- внешние API и интеграции служб доставки.

Демонстрационные данные на экранах не являются реальным анализом еды или медицинской рекомендацией.

## Сборка

Требуется JDK 17 и Gradle 8.13. В Android Studio можно открыть корневую папку проекта.

Локальная команда:
```bash
gradle :app:assembleDebug
```

APK:
`app/build/outputs/apk/debug/app-debug.apk`

## Сборка через GitHub без ПК

1. Создать пустой GitHub-репозиторий.
2. Загрузить содержимое архива в корень репозитория (не сам ZIP-файл).
3. Открыть вкладку Actions.
4. Запустить workflow `Build NUTRI APK` через Run workflow или отправить push в main.
5. После завершения открыть запуск workflow и скачать artifact `NUTRI-debug-apk`.

## Архитектурное направление

Следующие модули планируются отдельно:
- `data`: локальная база, репозитории, источники продуктовых данных;
- `domain`: расчёты КБЖУ, цели, правила диеты;
- `feature`: дневник, сканер, план питания, рецепты, доставка;
- `core`: дизайн-система, сеть, разрешения, хранение настроек.

API-ключи не добавлять в Git. Для личной сборки предусмотреть ввод ключа в настройках; для публичного релиза нужен защищённый backend/proxy.
